Critères détaillés
1. Respect des consignes (/5)

Exemple :

Prompt :

Le QCM doit être facile et destiné à des lycéens.

Évaluation :

Niveau facile respecté : +2
Sujet correct : +1
Format QCM respecté : +1
Nombre de questions demandé respecté : +1
2. Pertinence thématique (/5)

Questions possibles :

Toutes les questions concernent-elles Napoléon ?
Y a-t-il une contamination avec le machine learning ?
Des connaissances externes ont-elles été inventées ?

Barème possible :

5 : aucune erreur.
3 : quelques mélanges mineurs.
1 : confusion importante.
3. Adaptation au public (/5)

Pour un niveau lycée :

vocabulaire accessible ;
notions fondamentales ;
pas de concepts trop techniques.

Pour un niveau universitaire :

concepts plus complexes ;
analyse critique ;
mise en relation des notions.
4. Compréhension vs restitution (/5)

C'est probablement le critère le plus intéressant.

On pourrait distinguer :

Questions de mémorisation

En quelle année Napoléon devient-il empereur ?

Questions de compréhension

Pourquoi la centralisation administrative mise en place par Napoléon a-t-elle contribué à la stabilité du régime ?

Le second type mobilise davantage le raisonnement.

Tu pourrais calculer :

Taux de questions de compréhension =

(nombre de questions de compréhension)
/
(nombre total de questions)
5. Qualité rédactionnelle (/5)

Mesurer :

absence de fautes ;
clarté ;
formulation des propositions ;
unicité des bonnes réponses ;
équilibre de la difficulté.

Cohérence interne du QCM

Questions :

Existe-t-il plusieurs bonnes réponses involontaires ?
Certaines réponses sont-elles absurdes ?
Les distracteurs sont-ils crédibles ?
