**QCM : La Langue Française dans le Contexte de l'Arène Data Science**

**Instructions:** Choisissez la meilleure réponse parmi les quatre options proposées.

**Question 1:** Dans le contexte d'un projet Data Science, quelle est l'importance primordiale d'une API uniforme (comme `.fit`, `.predict`, `.score`) ?
   a) Elle rend le code plus esthétique.
   b) Elle permet de changer facilement d'algorithme sans modifier le reste du pipeline.
   c) Elle accélère l'exécution des algorithmes.
   d) Elle réduit la consommation de mémoire.

   **Réponse : b)** L'API uniforme garantit une standardisation, facilitant ainsi le changement d'algorithme et la modularité du code.

**Question 2:** Si une classe est sous-représentée dans votre ensemble de données, comment cela peut-il se manifester dans les résultats de vos modèles ?
   a) Le modèle ignorera simplement cette classe.
   b) Le modèle aura tendance à mal classer les instances de cette classe.
   c) L'accuracy globale du modèle sera toujours élevée.
   d) La matrice de confusion ne révèlera rien d'anormal.

   **Réponse : b)** Une classe sous-représentée peut entraîner un biais dans le modèle, conduisant à des erreurs de classification plus fréquentes pour cette classe spécifique.

**Question 3:** Quel est l'intérêt principal d'un graphique (diagramme en barres) par rapport à un simple classement numérique des accuracies ?
   a) Les graphiques sont toujours plus précis que les nombres.
   b) Les graphiques facilitent la visualisation et la comparaison rapide des performances des algorithmes.
   c) Les graphiques permettent de masquer les résultats médiocres.
   d) Les graphiques consomment moins d'espace mémoire.

   **Réponse : b)** La visualisation permet une interprétation plus intuitive et rapide des données, ce qui est crucial pour la prise de décision.

**Question 4:** Qu'est-ce qu'une matrice de confusion ?
   a) Un tableau contenant uniquement les bonnes réponses.
   b) Un tableau croisant les classes réelles et les classes prédites, montrant où le modèle se trompe.
   c) Une simple liste des erreurs commises par le modèle.
   d) Un outil pour calculer l'accuracy globale du modèle.

   **Réponse : b)** La matrice de confusion offre une analyse détaillée des erreurs de classification, permettant d'identifier les classes que le modèle confond souvent.

**Question 5:** Dans le contexte du cancer du sein, quelle est la conséquence la plus grave : rater une tumeur maligne ou alerter à tort sur une tumeur bénigne ?
   a) Les deux sont également graves.
   b) Rater une tumeur maligne car cela peut retarder un traitement vital.
   c) Alerter à tort sur une tumeur bénigne, car cela cause du stress et des examens inutiles.
   d) Cela dépend de l'âge du patient.

   **Réponse : b)** La détection manquée d'une tumeur maligne a des conséquences plus graves en termes de santé et de survie.

**Question 6:** Pourquoi le "buff scaling" (StandardScaler) peut-il améliorer les performances de certains algorithmes ?
   a) Il rend les données plus esthétiques.
   b) Il met toutes les colonnes sur une échelle comparable, ce qui est crucial pour les algorithmes sensibles aux distances.
   c) Il réduit le temps d'entraînement des modèles.
   d) Il augmente la complexité des modèles.

   **Réponse : b)** Les algorithmes basés sur les distances (comme KNN) sont particulièrement sensibles à l'échelle des variables, et le scaling permet de garantir que chaque variable contribue équitablement au calcul de la distance.

**Question 7:** Quel est le risque principal lors de l'ajustement du StandardScaler sur l'ensemble de données complet (avant le split train/test) ?
   a) Le modèle deviendra plus précis.
   b) Il y aura une fuite de données (data leakage), car le scaler utilisera des informations du jeu de test pour calculer la moyenne et l'écart type.
   c) L'entraînement du modèle prendra plus de temps.
   d) Le modèle sera moins généralisable.

   **Réponse : b)** La fuite de données compromet l'évaluation réelle des performances du modèle, car il aura indirectement accès à des informations qu'il n'aurait pas en production.

**Question 8:** Quel est le but principal du README de votre dépôt GitHub dans ce projet ?
   a) Décrire les détails techniques de chaque ligne de code.
   b) Expliquer le problème, les algorithmes utilisés, et justifier le choix du modèle retenu à quelqu'un qui n'est pas un expert en Data Science.
   c) Montrer votre capacité à utiliser GitHub.
   d) Lister tous les outils que vous avez utilisés.

   **Réponse : b)** La clarté de la communication est essentielle, et le README doit permettre à une personne non technique de comprendre l'objectif du projet et les raisons derrière vos choix.

**Question 9:** Pourquoi la relecture par un binôme (peer review) est-elle importante dans ce contexte ?
   a) Pour vérifier que le code est correctement indenté.
   b) Pour identifier d'éventuelles erreurs de logique, de fuite de données ou d'interprétation des résultats.
   c) Pour augmenter la vitesse de développement.
   d) Pour comparer les styles de codage.

   **Réponse : b)** La relecture par un pair permet d'obtenir une perspective différente et de détecter des problèmes qui pourraient être passés inaperçus.

**Question 10:** Qu'est-ce que le CRISP-DM ?
  a) Une bibliothèque Python pour l’analyse de données.
  b) Un algorithme d’apprentissage automatique avancé.
  c) Une méthode structurée en six phases pour mener à bien un projet Data Science.
  d) Un outil de visualisation des données.

   **Réponse : c)** CRISP-DM fournit un cadre méthodologique pour aborder les projets data science de manière systématique et efficace, en partant du problème métier jusqu'à l'évaluation du modèle.
