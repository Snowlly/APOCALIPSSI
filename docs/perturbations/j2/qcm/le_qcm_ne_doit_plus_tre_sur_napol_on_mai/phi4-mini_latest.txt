### Question 1:
Napoléon Bonaparte était très intéressé par l'innovation technologique. Si on lui avait proposé un modèle d'apprentissage automatique, quel type de problème spécifique pourrait-il avoir résolu en utilisant ce modèle?
- A) Chiffrer des communications militaires
- B) Classifier les batailles basées sur leur résultat (victoire ou défaite)
- C) Tracer le mouvement exact des armées ennemies
- D) Développer une nouvelle stratégie militaire

**Réponse : B**

Explication: Napoléon pourrait avoir utilisé un modèle d'apprentissage automatique pour classifier les batailles basée sur leurs résultats, ce qui lui permettrait de mieux comprendre quelles stratégies étaient efficaces.

### Question 2:
Dans le contexte du machine learning, quel est l'objectif principal lorsque vous appliquez une régression logistique à des données historiques?

- A) Déterminer la probabilité d'événements binaires
- B) Calculer les distances entre différentes observations géographiques
- C) Tracer un chemin optimal pour les opérations militaires
- D) Évaluer le sentiment exprimé dans des documents textuels

**Réponse : A**

Explication: La régression logistique est utilisée principalement pour déterminer la probabilité d'occurrences binaires en fonction de plusieurs variables indépendantes.

### Question 3:
Un ingénieur du machine learning essaie de préparer un dataset contenant des informations sur les tactiques militaires. Quel aspect spécifique devrait-il prioriser lors de l'élimination des valeurs aberrantes?
- A) Les erreurs dans le code qui génèrent des anomalies
- B) Des données incorrectes dues à une mauvaise saisie humaine
- C) Le sentiment ambiant capturé par des capteurs d'IA sur les champs de bataille
- D) L'interprétation correcte des résultats binaires

**Réponse : B**

Explication: Lors du nettoyage des données, il est crucial d'éliminer les valeurs aberrantes qui proviennent souvent de mauvaises saisies humaines.
